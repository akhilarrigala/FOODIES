# Foodies

Foodies is a modern web application designed for food enthusiasts to discover, review, and share their favorite recipes and restaurants.

## Features

- Browse and search for popular recipes and restaurants
- User registration and login
- Submit your own recipes and reviews
- Interactive rating and comment system
- Responsive design for mobile and desktop

## Getting Started

### Prerequisites

- Node.js (v18 or above recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/akhilarrigala/FOODIES.git
   cd FOODIES
   ```
2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```
3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and go to `http://localhost:3000`
