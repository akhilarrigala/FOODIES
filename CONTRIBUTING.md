# Contributing to Foodies

Thank you for considering contributing to Foodies! We welcome contributions of all kinds to help make this project better.

## How to Contribute

1. **Fork the repository**
2. **Create your feature branch** (`git checkout -b feature/YourFeature`)
3. **Commit your changes** (`git commit -m 'Add some feature'`)
4. **Push to the branch** (`git push origin feature/YourFeature`)
5. **Open a Pull Request**

## Guidelines

- Please make sure your code passes existing tests and linting.
- Write clear, concise commit messages.
- Describe your changes in detail in the pull request.
- Be respectful and constructive in discussions.

## Reporting Issues

If you find a bug or have a feature request, please [open an issue](https://github.com/akhilarrigala/FOODIES/issues) and provide as much detail as possible.

## Code of Conduct

This project adheres to a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

Thank you for helping make Foodies a great project!
